Chọn thư mục để bắt đầu

Thư mục văn bản chứa các file *.txt; mỗi thư mục kết quả chứa các file *.json. Các file được ghép cặp theo tên (ví dụ 12.txt ↔ 12.json).

  1. Chọn thư mục .txt trên máy bạn.
  2. Chọn kết quả A — xem một mình là đủ.
  3. Muốn so sánh: chọn thêm kết quả B, màn hình sẽ chia đôi và đánh dấu mọi khác biệt giữa hai run.

Không có gì được tải lên máy chủ — mọi thứ đọc và hiển thị ngay trên trình duyệt.

Di chuột hoặc bấm vào một nhãn để xem chi tiết JSON.
